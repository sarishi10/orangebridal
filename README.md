# Orange Bridal BCH — sales concept

Static GitHub Pages-ready concept website.

## Included
- Apple-inspired translucent navigation and layered depth
- Large editorial typography
- Responsive bento service layout
- Sticky scroll storytelling section
- Live Facebook page embed + links to official Instagram/Facebook
- WhatsApp enquiry CTA
- Google Maps embed
- Mobile responsive + reduced motion support

## Important
Facebook/Instagram block automated media scraping in many environments. This demo therefore references the official Facebook profile picture endpoint and official Facebook Page Plugin at runtime instead of copying social-media image files into the repository. For the strongest client pitch, replace the runtime social section with 6–10 approved original Orange Bridal photos and the official logo files supplied by the client/business owner.
